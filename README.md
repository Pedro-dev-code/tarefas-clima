# tarefas-clima

Aplicação web que reúne uma lista de tarefas e a consulta da previsão do tempo de qualquer cidade.

## Funcionalidades
- Adicionar, concluir e excluir tarefas (salvas no navegador com localStorage)
- Buscar o clima atual por cidade, consumindo a API Open-Meteo

## Tecnologias
HTML, CSS e JavaScript

## Como rodar
Baixe o projeto e abra o `index.html` no navegador.
